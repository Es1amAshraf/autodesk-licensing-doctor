كل اللي محتاجه لترتيب مشاكل الترخيص

مبني على ترتيب آمن: شوف الأول، خد نسخة احتياطية، غيّر بعدها، وتحقق في الآخر.

تشخيص كامل للجهاز

بيفحص خدمات الترخيص، الإصدارات المثبتة، وصلة Current، السجلات، الصلاحيات، ومتطلبات تسجيل الدخول — من غير أي تغيير.

نسخة احتياطية قبل أي تغيير

نسخة احتياطية متعددة الطبقات للخدمات، الريجستري، ملف hosts، متغيرات البيئة، وملفات الترخيص، مع سكربت UNDO جاهز للتشغيل.

تنظيف البقايا غير الصحيحة

بيشيل بقايا الترخيص غير الصحيحة المعروفة، الخدمات القديمة، مدخلات التشغيل السيئة، ومؤشرات الترخيص المزيفة — مع وضع معاينة قبل التنفيذ.

إصلاح المكونات الرسمية

بيثبّت حزم ADLS وAdSSO وIdentity Manager وWebView2 الرسمية من Autodesk / Microsoft، مع فحص التوقيع الرقمي قبل تشغيل أي ملف.

تبديل وضع الترخيص

بيعرض منتجات Autodesk المسجلة وبيبدّل وضع الترخيص بين User وStandalone وNetwork باستخدام الأداة الرسمية.

قنوات تحديث مزدوجة

تحديثات رسمية عبر شبكة GitHub Releases العالمية مع دعم تلقائي لمصدر updates.unlockdigital.online المباشر، وكل إصدار مفحوص ومطابق لـ SHA-256.

طريقة العمل

ترتيب آمن، مش خطوة عشوائية

ابدأ بفحص للقراءة فقط. مفيش أي تغيير بيحصل غير لما تختار الإجراء وتأكده.

  1. 1

    افحص

    اعمل تقرير حالة: الخدمات، الإصدارات، Current، السجلات، الصلاحيات، والمنتجات المثبتة.

  2. 2

    خد نسخة احتياطية

    سجّل الحالة الحالية وولّد سكربت UNDO قبل أي تعديل.

  3. 3

    نظّف

    عاين الأول، وبعدها شيل البقايا المعروفة غير الصحيحة.

  4. 4

    أصلح

    أعد تركيب المكونات الرسمية، وجّه Current للإصدار الصحيح، وشغّل خدمة الترخيص.

الأسئلة الشائعة

أسئلة قبل ما تشغّله

هل ده كراك أو أكتيفيتور؟

لا. الأداة لا تعدّل ملفات Autodesk ولا تولّد تراخيص. هي بتشيل البقايا غير الصحيحة المعروفة وتصلّح مكونات الترخيص الرسمية. لسه محتاج اشتراك Autodesk ساري.

هيشتغل مع 3ds Max 2023؟

أيوه. مسار الإصلاح بيتعامل مع ADLS / AdSSO المستخدمة في إصدارات 2021–2023، بما فيها 3ds Max 2023 (product key 128O1). وبيتعرف كمان على المنتجات الأحدث اللي بتستخدم Identity Manager.

يقدر يصلّح خطأ NLM في تسطيب AutoCAD 2027؟

أيوه، لو المشكلة سببها بقايا NLM محلية قديمة. الفحص بيظهر nlm-server-info.json وlicpath.lic ومفاتيح الريجستري ومتغيرات البيئة القديمة. الإصلاح بيعمل نسخة احتياطية مع UNDO، بيشيلها، يعيد تشغيل خدمة الترخيص، ويطلب منك تعيد تشغيل Windows قبل ما تجرّب تسطيب AutoCAD 2027 تاني. الأداة مش بتحذف خدمة NLM نفسها. لو الجهاز ده هو سيرفر الترخيص، حدّث NLM لـ 11.19.9.0+ بدل كده.

محتاج إنترنت؟

الفحص والنسخة الاحتياطية والتنظيف بيشتغلوا أوفلاين. الإصلاح يقدر يستخدم Installers موجودة عندك، أو ينزّل الحزم الرسمية من Autodesk / Microsoft لما تسمح بذلك. فحص التحديثات محتاج إنترنت.

بياناتي بتتبعت فين؟

مفيش تتبع. التقارير والسجلات بتفضل على الجهاز. الـ updater بيطلب ملف الـ manifest عبر HTTPS فقط، ولما تضغط Update بيطلب الـ Portable zip.

ليه Windows بيحذرني؟

لأن ملف الـ installer لسه غير موقّع رقميًا. تحقق من SHA256 مقابل القيمة اللي في الصفحة، وبعدها اختار More info → Run anyway. بعد التركيب، النسختين Setup وPortable بيفتحوا من خلال PowerShell الموقّع من مايكروسوفت، فبيشتغلوا على Windows 10 و11، حتى مع Smart App Control. لو جهاز مقفول منع ملف الـ installer نفسه بخطأ 4551، استخدم نسخة Portable؛ ومتوقفش SAC. البرنامج بيطلب صلاحيات Administrator لأنه بيصلّح خدمات ومكونات داخل Program Files.

أحدّث بعدين إزاي؟

استخدم زر Update جوه البرنامج. بيقرأ https://updates.unlockdigital.online/update.json، يقارن الإصدارات، يتحقق من SHA256، ويجهّز النسخة الجديدة. أو نزّل أحدث Setup من الصفحة دي.
